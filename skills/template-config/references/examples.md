Готовые конфиги ChatTemplater: полный набор файлов шаблонов и `Selector.json`.

## Раскладка

```text
addons/amxmodx/configs/ChatTemplater/
├── Templates/
│   └── default.json
└── Selector.json
```

## Templates/default.json

Массив объектов шаблонов:

```json
[
    {
        "Key": "say_default",
        "Template": "{p:name}^1: {chat:text}",
        "Description": "Обычный общий чат"
    },
    {
        "Key": "say_dead",
        "Template": "^1[МЁРТВ] {p:name}: {chat:text}",
        "Description": "Общий чат от мёртвого игрока"
    },
    {
        "Key": "say_vip",
        "Template": "^4[VIP]^1 {p:name}^1: {chat:text}",
        "Description": "Общий чат VIP с цветным префиксом"
    },
    {
        "Key": "sayteam_default",
        "Template": "(^3TEAM^1) {p:name}: {chat:text}",
        "Description": "Обычный командный чат"
    },
    {
        "Key": "sayteam_dead",
        "Template": "^1[МЁРТВ]^3TEAM^1 {p:name}: {chat:text}",
        "Description": "Командный чат от мёртвого игрока"
    },
    {
        "Key": "say_server",
        "Template": "^4[СЕРВЕР]^1 {p:name}: {chat:text}  ({map} | {time})",
        "Description": "Общий чат с глобальными плейсхолдерами"
    }
]
```

## Selector.json

Базовые ключи по каналу плюс уточнения по состоянию (необязательны, откат на
базовый ключ):

```json
{
    "Say": "say_default",
    "SayDead": "say_dead",
    "SayTeam": "sayteam_default",
    "SayTeamDead": "sayteam_dead"
}
```

## Пример: общий чат с именем и текстом

```json
{
    "Key": "say_default",
    "Template": "{p:name}^1: {chat:text}"
}
```

Результат: `Nick: привет`. Имя подставляется из `{p:name}`, `^1` возвращает
цвет по умолчанию, текст игрока приходит из `{chat:text}`.

## Пример: командный чат с меткой команды

```json
{
    "Key": "sayteam_default",
    "Template": "(^3TEAM^1) {p:name}: {chat:text}"
}
```

Метка `TEAM` окрашена командным цветом (`^3`), остальное цветом по умолчанию.

## Пример: обработка мёртвого игрока

Отдельный шаблон с префиксом состояния:

```json
{
    "Key": "say_dead",
    "Template": "^1[МЁРТВ] {p:name}: {chat:text}"
}
```

Чтобы он применялся только к мёртвым, свяжите его с ключом `SayDead` в
`Selector.json` (см. выше). Встроенный селектор сам определяет живость по
игроку; если ключ `SayDead` не задан, для мёртвых используется `Say`.

## Пример: цветной префикс через `^`-коды (без RGB)

```json
{
    "Key": "say_vip",
    "Template": "^4[VIP]^1 {p:name}^1: {chat:text}"
}
```

Префикс `[VIP]` зелёным (`^4`), дальше стандартным цветом (`^1`). Сырые байты
цвета писать не нужно: `ChatTemplate` сам превращает `^1` / `^3` / `^4` в
коды движка.

## Пример: глобальные и игровые плейсхолдеры вместе

```json
{
    "Key": "say_info",
    "Template": "{p:name}^1 [{p:frags} фрагов, {p:health} HP]: {chat:text}  ({map})"
}
```

Смешивать глобальную группу (`{map}`) и группу игрока (`{p:...}`) в одной
строке можно свободно.

## Что проверить

- Каждый `Key` уникален по всем файлам `Templates/`.
- `Selector.json` ссылается только на существующие ключи.
- Уточняющие ключи состояния (`SayDead`, `SayTeamT`, ...) ссылаются на
  существующие `Key`; незаданные откатываются на базовый ключ, а `say_team` —
  на `say` того же состояния.
- `{chat:text}` есть в каждом шаблоне, где должен быть текст игрока.
- Цвета только через `^1` / `^3` / `^4`.
- Строка укладывается в предел длины (~190 ячеек).
